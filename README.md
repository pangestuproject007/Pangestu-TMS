# PangestuTMS

Theater Management System (Tornado + SNMP/SOAP) for projector and IMS monitoring.

## Setup
1. `copy backend\config.example.json backend\config.json` and fill in your screens/credentials.
2. `copy backend\users.example.json backend\users.json` and set a real admin password.
3. Run `START_TMS.cmd` (http://localhost:5050).

`config.json` and `users.json` are git-ignored because they contain credentials.
